# HP ZBook 15 G6 EasyEffects Preset

## Archived Notice
This project is now archived due to the better [Speaker Tuning to EasyEffects](https://github.com/antoinecellerier/speaker-tuning-to-easyeffects) repository. Please use that to generate a preset for your system.

## Original Description

An EasyEffects preset for the Bang &amp; Olufsen speakers on the HP ZBook 15 G6 utilizing the Realtek ALC285 codec, for necessary speaker amplification and balancing. 

While the HP Clear Sound Amp module is set to be powered on ([Source](https://lkml.iu.edu/hypermail/linux/kernel/2112.1/03834.html)), its amplification and balancing effects are not present, leading to a very flat and empty speaker. This preset mimicks the missing feature.
